          四层记忆是什么？
          
L0 对话流水：原始问答原文，按日期存于 conversations/日期.jsonl
L1 原子记忆：从对话提炼出的单条事实（偏好/决策/技术栈），可在此编辑和删除——改这里，下次提炼会自动同步到 L2/L3
L2 场景记忆：按主题归类的 MD 文件（如"盲人导航项目"），内核自动维护，只读
L3 用户画像：长期沉淀的用户理解（persona.md），内核自动生成，只读
想改记忆改 L1；直接手改 L2/L3 文件可能被下次提炼覆盖。

客户端接入（TRAE / WorkBuddy / 其他）

        
会话标识（session_key）：记忆的“档案柜名”。多个客户端填同一个标识，记忆才会聚到同一空间。

        

          
          
        

        
HTTP 桥（豆包用）：检测中…

        
豆包等只支持「服务器 URL」的客户端：设置 → 自定义连接器 → 名称填 agent-memory、URL 填 http://127.0.0.1:8410/mcp、传输类型 HTTP、Headers 留空，保存后用上面同一个 session_key 的规则文本即可。

        
懒人模式：勾选客户端后点写入（写入前自动备份原文件，只动 agent-memory 一项，其他 MCP 原样保留）。TRAE 没有本地配置文件，仍需手动粘贴。

        

        
        

        
第一步：把 MCP 配置 JSON 添加到客户端的 MCP 服务器设置。路径已按本机自动生成——换电脑或移动软件文件夹后，在新机的本页面重新复制一次即可，无需手改。

        
        

          

          
        

        
第二步：把记忆规则粘贴到客户端的自定义指令 / 提示词设置（规则文本会自动带上上面设置的 session_key）
